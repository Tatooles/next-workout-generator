# Workout Generator

A Next.js app for generating single-workout plans and weekly training programs from structured fitness preferences.

## Development

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Quality Checks

```bash
pnpm lint
pnpm build
```

## Configuration

The API routes call OpenRouter and require:

```bash
OPENROUTER_API_KEY=...
```
